# 技术设计：项目创作配置

## 存储

新增一对一项目创作配置记录，使用版本化 JSON 保存易扩展的选择和参数，并通过 Pydantic Schema 统一校验。记录包含配置版本、项目 ID、更新时间，不包含密钥。

配置结构至少包含：

- 章节和分析的 provider_config_id/model；
- 默认 Skill key；
- 默认写作风格 ID；
- MCP 是否允许及可选插件 ID；
- 章节字数、温度、最大 Token；
- Pipeline 预算、检查点和推进参数。

## 解析规则

项目显式配置优先；字段为空时解析用户任务路由或系统默认，但把最终结果冻结进本次生成记录或 Pipeline 运行快照。资源失效时返回明确错误，不静默改用另一个模型。

Skill 和风格在运行时记录 key/ID、名称、内容摘要和版本哈希；AI 服务只记录服务 ID、协议和模型，不保存 API Key；MCP 只记录策略和插件 ID，不复制连接凭据。

## 交互边界

本任务先提供后端读写和解析能力。完整项目设置 UI 由 Pipeline 整改及单副本 UI 任务接入。旧项目没有记录时返回兼容默认配置，并在用户首次保存时落库。
