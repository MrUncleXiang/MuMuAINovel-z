# 技术设计：Pipeline 接回正式底座

保留 NovelPipeline 的状态机、预算、暂停/恢复和检查点外壳，替换章节循环内部实现。

启动或继续时，Pipeline 从项目创作配置生成自己的运行快照；运行中始终使用该快照，用户要修改配置需先暂停并显式应用新版本。每章调用正式章节生命周期模块，并等待分析任务成功后才增加完成计数、预算和进入下一章。

分析失败、配置资源失效或向量写入失败都使 Pipeline 暂停并显示可恢复错误，不进入下一章。停止和回滚不删除项目配置。

配置面板读取/写入同一 Schema，补齐 Skill、风格和 MCP 控件，避免前端自己拼另一种配置结构。
