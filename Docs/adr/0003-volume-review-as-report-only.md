# 3. 卷检查只出报告不改文

日期：2026-08-11

## 状态

接受

## 背景

跨章节的连贯性/逻辑问题（时间线、伤势延续、战力越级、伏笔回收）需要对照整卷检查，但单章生成时全书档案不完整，不适合放进每章自动审查。卷末体检需求出现后，面临"AI 直接改 vs 只出报告"的选择。

## 决策

- 卷卡片「🔍 卷检查」→ 后台任务：对卷内每章执行完整审查（复用审查引擎，`apply_fix=False` 只审不改）+ 跨章 continuity 检查（各章摘要 + 角色档案）。
- 产出"章节 → 问题列表"（类型/描述/建议/级别），结果弹窗每章一个选项卡展示。
- 修改动作由用户决定：单条「AI 根据建议修改」或同类型「一键合并修改」（均先 diff 确认），或跳转章节手动编辑。

## 备选方案

- AI 直接改相关章节：跨章自动修改风险大（按下葫芦浮起瓢）、一次多章 token 消耗高 → 未采纳。

## 后果

正面：跨章问题被系统化发现（实测抓到"三章正文雷同"）；修改权在人，安全可控；审查记录入库可在章节列表随时查看。
负面：多一步人工确认，不能一键全自动修完一卷。
