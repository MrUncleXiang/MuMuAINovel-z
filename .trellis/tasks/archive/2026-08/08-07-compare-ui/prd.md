# PRD：双模型对比创作三入口

> **已冻结，禁止实施。** 一次创建两本并自动启动的编排已被否决。本文只保留为历史证据，后续由 `08-07-compare-single-clone-ui` 的“一次创建一本、用户检查后手动启动”流程替代。

> 任务：08-07-compare-ui（P1）
> 状态：planning

## 目标

在灵感模式完成页、建书向导完成页、流水线驾驶舱提供同一个“用两个模型对比创作”流程。当前书只作为设定模板；系统创建 A、B 两本全新对比书并分别启动流水线，源书不修改、不启动、不清空。

## 统一弹窗

三个入口复用一个 `CreateComparisonModal`，使用 Ant Design 表单，包含：

- 模型 A：AI 服务、该服务下的模型；
- 模型 B：AI 服务、该服务下的模型；
- 生成章节数：1-200，默认 10；
- 两个模型组合不能完全相同；只显示当前用户已启用的服务，不显示密钥。

弹窗正文明确说明“会从当前设定创建两本新书，原书不变”。窄屏表单单列显示。

## 调用流程

1. 完成页必须保存并传入实际 `projectId`；没有项目 ID 时不显示入口。
2. 校验两组服务/模型及章节数后锁定按钮，避免重复提交。
3. 分别调用 clone API，后缀使用可辨认的模型显示名；只有两本都复制成功后才启动流水线。
4. 两本书使用相同的流水线参数，唯一差异是模型配置。所选 provider/model 写入 `book/chapter/analysis/volume_transition` 四个阶段；`milestone_chapters` 使用弹窗章节数。
5. 两条流水线并行启动。全部成功后跳转 `/compare?left=<A>&right=<B>`。

## 失败处理

- 复制阶段失败：删除本次已经成功创建、但尚未启动的副本；删除失败时在错误中给出残留书名，方便用户手动处理。
- 启动阶段部分失败：停止已启动的另一条流水线，不删除两本书；保留弹窗并提供“重试启动”。已经生成的内容不得静默删除。
- 所有错误使用简短中文说明；按钮在请求结束前保持禁用。

## 三个入口

1. 灵感模式生成完成页：主操作旁显示“用两个模型对比创作”。
2. 建书向导生成完成页：显示同一按钮。
3. 流水线驾驶舱：无论源书是否已有正文均可使用，因为源书只作为模板，A/B 都是新建的干净副本。

## 验收

1. 三个入口打开的是同一个组件，字段、校验和文案一致。
2. 选择两个不同模型和 5 章后，创建两本设定相同的新书，并各自启动目标为 5 章的流水线。
3. A/B 的流水线配置快照除模型外一致，四个生成阶段分别固定到所选模型。
4. 源书的内容、状态和流水线不发生变化。
5. 连续点击不会重复建书；复制或启动部分失败按上述规则补偿并给出可操作提示。
6. 桌面和手机宽度下无字段遮挡，键盘可完成选择、提交和关闭。
