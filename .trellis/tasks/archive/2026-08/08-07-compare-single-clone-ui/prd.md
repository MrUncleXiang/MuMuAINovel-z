# PRD：单副本创建与书籍管理入口

## 目标

把“创建对比副本”做成持久化项目操作，而不是一次性双模型运行向导。

## 交互

- 从书架、项目详情或流水线页面发起；
- 提供“从头开始”或“继承至第 X 章”选项；选择继承时展示可继承章节范围和将一并复制的过程数据摘要；
- 审查当前模型、写作风格、Skill、MCP 和分析配置是否已有可编辑界面。已有配置默认带入副本；缺少交互的配置必须在实施前补齐方案；
- 创建成功后刷新书架并进入副本项目，不自动启动，或明确提供“进入后启动”的独立按钮；
- 副本标题包含模型标签，但仍可修改；
- 副本后续按普通项目管理，模型和推进设置在其自己的流水线页面修改；
- 失败时显示原因，不创建第二本隐式副本。

## 非目标

- 不在此入口同时选择模型 A/B；
- 不自动创建两本书；
- 不把正文放在临时对比页或浏览器缓存中。

## 验收

- 创建后书架可见新项目，刷新页面仍存在；
- 源书和副本可以分别暂停、继续、修改模型和推进参数；
- 副本可进入 Skill、章节生成、章节分析、伏笔、记忆和角色关系等原有页面；
- 手动选择两本已有书时，对比页只读显示，不触发生成。

本轮不实现或入口化“两本书并排阅读”；最后一条保留为未来独立任务约束。

## 依赖

- 项目深复制 v2 API 完成；
- 项目配置和 Pipeline 面板能够检查并修改副本配置。
