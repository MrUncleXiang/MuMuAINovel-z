# 批量生成自动接管前置分析（失败/缺失自动重析，成功后继续）

## Goal

「写这卷正文」/批量生成遇到上一章分析失败/未分析时不再卡住报错：执行链自动重新分析上一章（进行中则等待），成功后继续本章正文生成；再次失败才中断并报错。`skip_analysis_check` 勾选时保持跳过。创建任务预检不再 409 拦截（执行时自动接管）。

## Requirements

1. 新增 `_ensure_previous_analysis_ready`（执行链自动接管）：
   - 上一章分析**就绪** → 直接继续
   - 分析**进行中**（pending/running）→ 轮询等待（最多 10 分钟）
   - 分析**失败/缺失/内容变更** → 自动重新分析（同步等待完成）
   - 等待超时 / 自动重析失败 → 返回明确错误终止任务（提示可勾选跳过）
2. `execute_batch_generation_in_order` 集成：`check_previous_analysis_ready` 不通过且未勾选跳过时，调用自动接管而非直接中断。
3. 移除创建任务时的 409 预检拦截（改为执行链自动接管）。
4. `skip_analysis_check` 勾选时：跳过检查与接管，直接生成。

## Acceptance Criteria

- [x] 前章分析失败 → 批量生成自动重新分析（日志 `🔄 自动接管：...自动重新分析...`）→ 成功后续章正文生成，任务 completed
- [x] 前章无分析记录 → 同样自动重析
- [x] 已写正文不被覆盖（实测第1章内容保持）
- [x] 勾选跳过 → 不接管不拦截直接生成
- [x] 等待分支逻辑修正：任务"完成但内容不匹配/失败/消失"时不再误报超时，正确落入重析分支（审查修复）
- [x] 端到端实测：临时项目前章分析失败 → 自动重析（28s）→ 第2章正文 5586 字生成成功
