# Component Guidelines

- Functional React components with typed props and Ant Design controls.
- User-facing explanations and errors are concise Chinese; assume a nontechnical user.
- Keep shared selection/comparison behavior in reusable components.
- Candidate cards show provider, model, status, duration and token usage without secrets.
- Support card reading and two-result side-by-side/diff comparison; mobile falls back to stacked cards.
- Adoption or destructive actions require confirmation and explain which formal content changes.
