# 自动化小说生产流水线——实现蓝图（v1）

> 来源：wayfinder 地图 `.scratch/auto-novel-pipeline/`，7/7 票全部解决。
> 状态：已确认蓝图，待 Rudder 分批施工。

## 一、目标

在 MuMuAINovel 中实现一条自动化小说生产流水线：
从**题材模板选择**开始 → **一键建书** → **章节自动推进** → **人工检查点**（继续/回滚重写），
支持**预设里程碑**（如"写完前 50 章暂停"），无硬性终点（用户喊停才停）。

## 二、架构总览（4 阶段）

```
阶段1 一键建书 ──→ 阶段2 章节循环 ──→ 阶段3 检查点暂停 ──→ 阶段2/4
（后台跑现有    （取当前卷→逐章     （面板内审阅：    （卷过渡：当前卷
  向导4步）      生成→自动分析）      正文+分析+对比）   写完→生成下卷
                                                      Outline→回阶段2）
```

- **阶段 1 一键建书**：后台执行现有向导 4 步（世界观→职业体系(可选)→角色→多卷大纲）。
  题材模板选择 = 建书入口的输入（选模板或自定义 → 一键开书），不是独立阶段。
- **阶段 2 章节循环**：取当前卷(Outline) → 逐章生成（后台模式）→ 每章自动分析 → 判断"到检查点了吗？"
- **阶段 3 检查点**：暂停等用户。展示本次检查点覆盖章节的正文+分析+可选多LLM对比。
  动作：继续 / 回滚重写 / 暂停（改天再说）。
- **阶段 4 卷过渡**：当前卷章节写完 → 自动生成下一卷的 Outline → 回阶段 2。

## 三、检查点（决策 04 + 05）

**粒度（组合、全部可配）：**
1. 每 N 章停一次（N 可配，默认 10）
2. 每卷结束必停
3. 里程碑强制停（已生成章节总数 ≥ 里程碑数字，如 50）
4. 用户随时手动暂停

三个条件独立，任一满足即触发检查点。

**里程碑定位：**
- 独立全局计数器，与"每 N 章"可同时生效
- UI 要求：里程碑与"每 N 章"两个设置**分开罗列、放同一区域**

**回滚语义：**
- 回退内容：默认只回退章节正文（A）；可选"正文+大纲"（B）
- 回退深度：可回退到**任意历史检查点**
- 旧内容：纯删除，不留回收站
- 重写：走现有"带反馈重写"（可写要求/换模型/换风格），无需特殊设计
- 回退可重复执行，无特殊状态

## 四、题材模板（决策 01）

- **不自动爬榜单**。采用"题材模板选择"模式：
  - 模板库初始建立：firecrawl 一次性采集目标平台（番茄/起点等）当前热门榜 → 提炼模板；
    或用户手动给例子 → AI 分析出模板
  - 每套模板含：题材名、标签、世界观公式、角色原型、常见卷结构
  - 用户在模板库选一个（或自定义）→ 一键开书 → 进入流水线
  - 模板库不需持续更新（手动刷新即可）
- 施工前技术调研：firecrawl API 额度、目标榜单 URL、模板数据结构

## 五、前端（决策 06）

- **流水线面板**：项目详情页左侧菜单最上面加"流水线"入口，独立页面（驾驶舱）
- **审阅界面**：检查点暂停后，面板进入"审阅模式"——列出本次覆盖章节，每章可展开看
  正文+分析+多LLM对比，底部操作按钮（继续/回滚重写/暂停）。复用现有组件，不跳页。
- **建书配置**：建书向导加"流水线设置"区域（启用开关 + 默认值预填：里程碑 30 章、
  每 10 章检查、默认模型、默认预算 ¥30）；运行中面板随时可改。
- **状态展示**（三层组合）：
  - 上层：阶段流程线（建书→章节循环→检查点→卷过渡），当前阶段高亮
  - 中层：当前阶段内进度（这卷写到第 12/30 章）
  - 下层：下一个检查点提示（还有 8 章停一次 / 距里程碑还有 38 章）

## 六、LLM 路由与预算（决策 07）

- **默认模型**：所有阶段默认 OpenCode Go / deepseek-v4-flash；每阶段可自定义为其他已配置 LLM
- **多 LLM 对比**：任何阶段可开（开关 + 手动选 2–3 个模型 + 分额度控制）
- **预算**：人民币估算金额 + tokens 双显示；到上限自动暂停 + 提醒；
  用户可加预算继续 / 保持暂停 / 换便宜模型再继续；建书时设、运行中可改
- **生成参数**：每阶段独立暴露 temperature / max_tokens

## 七、数据与基础设施（决策 02/03，来自 research）

- **分卷**：不新增 Volume 模型。沿用现有 Project→Outline→Chapter 结构，每条 Outline = 一卷。
- **新增组件**：
  - Pipeline Orchestrator（流水线编排器）：读当前阶段→判断下一步→触发生成→挂起等检查点→用户信号继续
  - 章节后台生成模式（现有 generate-background / batch-generate-in-order 已有雏形，整合进编排器）
- **章节状态升级**：正式状态枚举（新增 awaiting_review、rewriting_rollback 等流水线状态）
- **复用**：TaskProgressTracker（进度/取消）、用户级写锁、多 LLM 对比批次、分析服务
- **新增数据**：流水线运行记录（当前阶段、进度、配置快照、检查点历史）

## 八、边界（Out of scope）

- 内容发布/分发到外部平台
- AI 自动完结判定（完结仍为人工判断）
- 多语言/翻译
- 持续自动爬取榜单（一次性采集即可）
