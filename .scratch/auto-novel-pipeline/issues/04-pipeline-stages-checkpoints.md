# 流水线阶段与检查点粒度设计

Type: grilling
Blocked by: 02, 03
Status: resolved

## Question

基于已有的建书流程和章节状态机，流水线应该分哪几个阶段？（候选：题材确认→建书→分卷→大纲生成→章节生成→分析→审阅检查点→下一章/下一卷循环）每个阶段的触发条件、完成条件、到下一阶段的转换条件是什么？

检查点粒度：每章停一次？每 N 章停一次（N 可由用户设）？每卷停一次？还是多种粒度叠加（每卷必停 + 每 N 章可选停）？

里程碑（如"写完前 50 章暂停"）在状态机里占哪个位置——是一个特殊的"卷级检查点"还是独立概念？

## Answer

**1. 阶段划分（4 阶段，已确认）：**
- 阶段 1：一键建书（后台跑现有向导 4 步：世界观→职业体系(可选)→角色→多卷大纲）
- 阶段 2：章节循环（取当前卷→逐章生成→每章自动分析→判断是否到检查点）
- 阶段 3：检查点暂停（展示正文+分析+可选多 LLM 对比；用户选继续/回滚重写/暂停）
- 阶段 4：卷过渡（当前卷写完→自动生成下一卷 Outline→回阶段 2）

**2. 检查点粒度（选 D，组合、全部可配）：**
- 每 N 章停一次（N 可配，默认 10）
- 每卷结束必停
- 里程碑强制停（章节总数 ≥ 里程碑数字）
- 用户随时可手动叫停
- 三个条件独立，任何一个满足即触发检查点

**3. 里程碑定位（独立概念 + 可同时使用）：**
- 里程碑 = 全局进度计数器，不是卷级检查点
- 里程碑与"每 N 章"可同时生效（都设了就都会停）
- ⚠️ UI 要求（用户提出）：里程碑与"每 N 章"两个设置在交互界面上**分开罗列、放在一起**（两个独立设置项，同一区域展示）

**4. 题材模板位置：**
- "题材模板选择"发生在建书入口（选模板或自定义 → 一键开书），是阶段 1 的输入，不是独立流水线阶段

---
Resolved. 4阶段+组合检查点+里程碑独立可同时用+UI分开罗列。
