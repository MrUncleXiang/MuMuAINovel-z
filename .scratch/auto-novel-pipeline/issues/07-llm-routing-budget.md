# 各阶段 LLM 路由与成本预算设计

Type: grilling
Blocked by: 04
Status: resolved

## Question

每个流水线阶段对模型的需求不同（题材分析可能用便宜模型、正文写作用高质量模型、多 LLM 对比可能同时用 2-3 个模型）——具体怎么配？

- 各阶段默认推荐什么模型/供应商组合？（基于已有配置：hubway、vc-grok、OpenCode Go + .env 默认中转）
- 多 LLM 对比模式：哪些阶段可以开？（选题材分析？正文写作？）用户选好模型后，对比结果怎么呈现到检查点审阅界面？
- 费用控制：预算以"tokens 上限"还是"估算金额"为单位？到上限后是停流水线还是发通知？用户在建书时设一次，还是运行中可以调整？
- 不同阶段的 temperature、max_tokens 等参数要不要独立配置？

## Answer

**1. 各阶段默认模型（全部默认 OpenCode Go / deepseek-v4-flash）：**
- 所有阶段（题材分析、建书、正文、分析）默认统一用 deepseek-v4-flash
- 用户可在每个阶段自定义为其他已配置的 LLM（vc-grok 等）

**2. 多 LLM 对比（选 C，任何阶段可开）：**
- 提供开关 + 手动选模型（2–3 个）+ 分额度控制
- 任何阶段都能开（正文/大纲/建书/分析），不限于正文
- 对比结果呈现在检查点审阅界面（复用现有对比组件）

**3. 费用控制：**
- 单位：人民币估算金额 + tokens 双显示
- 到上限：自动暂停流水线 + 提醒；用户可加预算继续 / 保持暂停 / 换便宜模型再继续
- 设定时机：建书时设（默认值预填，如 ¥30）+ 运行中随时可改

**4. 生成参数（选 B）：**
- 每个阶段独立暴露 temperature、max_tokens 配置（用户可调）
- 与模型选择并列展示

---
Resolved. 全阶段默认 deepseek-v4-flash 可自定义；多LLM对比任何阶段可开；金额+tokens双显示、超限暂停可加预算；每阶段独立暴露温度/token参数。
