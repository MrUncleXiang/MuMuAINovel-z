# 流水线前端体验设计

Type: grilling
Blocked by: 04
Status: resolved

## Question

流水线管理面板放在哪里（项目管理页里一个 tab？独立页面？）？

审阅界面：已有章节页/大纲页是否能直接承载"检查点审阅"体验，还是需要新建一个"审阅面板"（集中看正文+分析+多 LLM 对比+操作按钮）？

建书配置：启用流水线的选项是放在已有的智能向导里（建书时一步搞定），还是建好书后在"项目设置"里单独配（里程碑、模型选择、预算上限、检查点频率等）更合理？

流水线运行中的状态该怎么展示（进度条？时间线？阶段图标？）——让非技术用户一眼看出"现在跑到哪了、下一个检查点在哪"。

## Answer

**1. 管理面板位置（选 A）：**
- 项目详情页左侧菜单**最上面**加"流水线"入口，独立页面（与角色/大纲/章节平级）
- 面板 = 这本书的"驾驶舱"，管节奏；内容页（大纲/章节）管内容，各司其职

**2. 审阅界面（选 A）：**
- 检查点暂停后，流水线面板直接进入"审阅模式"：列出本次检查点覆盖章节，每章可展开看正文+分析报告+多 LLM 对比，底部操作按钮（继续/回滚重写/暂停）
- **复用现有组件**（章节分析、多 LLM 对比界面嵌进来，不重新造轮子）
- 审阅在面板内完成，不跳页

**3. 建书配置（选 C）：**
- 建书向导加"流水线设置"区域：启用流水线 + 默认值预填（里程碑 30 章、每 10 章检查、默认模型、默认预算）
- 建好后流水线面板**随时可改**（含运行中）：检查频率、模型、预算、里程碑均可调整
- 跳过设置也能建书（默认值兜底）

**4. 状态展示（选 C，组合）：**
- 上层：阶段流程线（建书→章节循环→检查点→卷过渡），当前阶段高亮
- 中层：当前阶段内进度（这卷写到第 12/30 章）
- 下层："下一个检查点"提示（还有 8 章停一次 / 距里程碑还有 38 章）

**附带要求（来自 04）：** 里程碑与"每 N 章"两个设置在界面上**分开罗列、放一起**（两个独立设置项，同一区域）。

---
Resolved. 侧边栏最上独立面板；面板内审阅复用现有组件；建书向导配置+运行中可改；阶段流+进度+下个检查点组合展示。
